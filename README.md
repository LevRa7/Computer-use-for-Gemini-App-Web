## 💡 Что это такое?

**Gemini Computer Use** — это открытое и бесплатное решение для прямого управления вашим компьютером, ноутбуком или удалённым сервером из диалогового окна **Google Gemini** (включая веб-версию [gemini.google.com](https://gemini.google.com), мобильное приложение Gemini и Google AI Studio).

В отличие от закрытых или платных аналогов, проект использует официальный протокол **Model Context Protocol (MCP)** от Google и работает поверх защищённого WebSocket-туннеля или в локальном автономном режиме.

---

## ✨ Ключевые возможности

- 🆓 **100% Бесплатно**: Работает с бесплатным тарифом Google Gemini (Web и Mobile App).
- ⚡ **Установка в одну команду (One-Line Setup)**: Скрипт сам определяет тип устройства (ноутбук/десктоп/VPS/сервер), ОС и архитектуру.
- 🌐 **Два режима работы**:
  1. **Cloud Gateway + Reverse Tunnel**: Работает из-за любого «серого» IP, роутера и NAT. Не требует открытия входящих портов.
  2. **Local Standalone**: Полностью локальный FastMCP-сервер на `localhost:8096` без внешних зависимостей.
- 🛡️ **Строгая безопасность**: Каждый запрос к инструментам защищён персональным 128-битным криптографическим токеном (`?token=...`). Доступ посторонних строго отсекается (HTTP 401).
- 📡 **Удалённая установка через SSH**: Возможность развернуть узел на удалённом сервере одной командой прямо из локального терминала (`--ssh=user@host`).
- 🔄 **Автозапуск**: Автоматическая интеграция со службой `systemd` (user-level linger), узел работает в фоне и переживает перезагрузки.
- 📱 **Управление со смартфона**: Пишите команды в мобильном приложении Gemini на прогулке — ваш ноутбук или домашний сервер мгновенно их выполнит!

## 🛠️ Доступные MCP-инструменты

Модель Gemini получает прямой доступ к инструментам:
- `bash_exec(command)` — автономное выполнение shell-команд, сборки кода, тестов, git-операций на вашей машине.
- `system_vitals()` — мониторинг нагрузки в реальном времени: загрузка CPU, использование RAM и диска.
- `get_orchestration_skill()` — динамическая доставка системного скилла и инструкций оркестрации инфраструктуры.

## 🚀 Быстрый старт

#### 🐧 Linux & 🍎 macOS (через curl):
```bash
curl -fsSL https://smart-server.online/install.sh | bash
```

#### 🪟 Windows (через PowerShell):
```powershell
irm https://smart-server.online/install.ps1 | iex
```

#### 📦 Node.js / NPM (Кроссплатформенно):
```bash
npx gemini-computer-use
```

#### 🛠️ Либо вручную через Git:
```bash
git clone https://github.com/LevRa7/Gemini-APP-Web-for-computer-use---FREE.git
cd gemini-computer-use
./install.sh --quick
```

Мастер установки автоматически:
1. Определит тип устройства и хостнейм.
2. Зарегистрирует персональный защищённый субдомен.
3. Сгенерирует уникальный крипто-токен авторизации.
4. Настроит и активирует автозапуск службы `systemd`.
5. Выведет готовый защищённый URL для добавления в Gemini.

---

### 2. Подключение к Google Gemini

1. Откройте **[gemini.google.com](https://gemini.google.com/)** (в браузере или приложении).
2. Нажмите на иконку настроек ⚙️ ➔ **Инструменты / Расширения (MCP)**.
3. Добавьте сервер и вставьте выданный установщиком URL:
   ```text
   https://<имя-вашего-пк>.smart-server.online/sse?token=<ваш_секретный_токен>
   ```
4. Готово! Теперь в диалоге с Gemini можно просить:
   - *«Выведи аптайм и статус диска через system_vitals»*
   - *«Создай проект на FastAPI и протестируй его через bash_exec»*
   - *«Сделай git commit и запушь изменения»*

## 🖥️ Режимы развёртывания

### Вариант А: Быстрая настройка через шлюз (Рекомендуется)
```bash
./install.sh --quick
```
Идеально для ноутбуков и домашних ПК за NAT. Связь держится через исходящий WebSocket.

### Вариант Б: Локальный Standalone (без субдомена и шлюза)
```bash
./install.sh --mode=standalone --port=8096
```
Запускает чистый локальный FastMCP-сервер на `http://localhost:8096/sse`.

### Вариант В: Удалённая установка на SSH-сервер
```bash
./install.sh --ssh=user@my-remote-server.com
```
Автоматически перенесёт файлы по SSH и запустит настройку на удалённом сервере.

## 🔒 Модель безопасности

- **Аутентификация по токену**: Ни один запрос не выполнится без валидного токена в параметре `?token=...` или заголовке `Authorization: Bearer`.
- **Исходящий туннель**: Локальный агент держит только исходящее соединение, ваши домашние порты остаются закрытыми от внешнего сканирования.
- **Изоляция окружения**: Команды исполняются от имени локального пользователя без необходимости root-прав.
