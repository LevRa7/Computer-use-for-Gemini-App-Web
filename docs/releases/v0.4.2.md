## 🔧 Antigravity Mesh v0.4.2

Two delivery fixes: the documented one-liners now name a host that actually
resolves, and the README renders in Russian again. No node behaviour changed.

### 🌐 The install one-liners point at the gateway that answers

`smart-server.online` has been on a registry **serverHold** since 2026-10-06 and
answers **NXDOMAIN**, so every documented one-liner and every bootstrap that
named it fails to resolve — while the gateway itself is up. It is reachable at
`https://racknerd-5a24bf9.merino-carob.ts.net`, which Tailscale serves publicly.

- README (en/ru): the install one-liners for Linux/macOS, Termux and Windows,
  the Streamable-HTTP MCP link example, the visual-installer table row and both
  architecture diagrams now name the Tailscale host.
- `bin/cli.js`: `npx gemini-computer-use` bootstraps from the same host, so the
  Node entry point no longer sends a new user to a dead name.
- Unchanged on purpose: `core/domain.py`'s built-in default stays a fallback,
  and the certificate's lineage name stays `smart-server.online`. A served copy
  still learns its own domain from `PUBLISHED_DOMAIN`, which `deploy_gateway.sh`
  rewrites — a gateway re-published under the Tailscale name needs no code
  change at all.

Until the domain hold clears, a device that is *not* on the tailnet should pass
the host explicitly: `curl -fsSL https://racknerd-5a24bf9.merino-carob.ts.net/install.sh | bash -s -- --domain=racknerd-5a24bf9.merino-carob.ts.net`.

### 📝 The README's Russian text renders again

The v0.4.1 README shipped with its Cyrillic double-encoded: UTF-8 bytes had been
decoded as CP1251 and written back as UTF-8, so 409 lines of the Russian half
rendered as `РџСЂ…` mojibake while the bytes stayed valid UTF-8.

- The damage was reversed losslessly — a byte-exact inverse round-trip was
  verified — and the line count is identical (1094). No wording changed.
- A tree-wide scan of every tracked text file finds no other double-encoded file.

### 📦 Package

`gemini-computer-use@0.4.2` — same file list as 0.4.1, with the repaired README
and the Tailscale bootstrap targets.
