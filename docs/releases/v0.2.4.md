## 🚀 Antigravity Mesh v0.2.4

Documentation-only release: it refreshes the README that ships inside the package.
The code is identical to v0.2.3.

### 📝 Changes

- README repositioned as a mobile agent for **Gemini Spark (App & Web)**.
- Release notes are versioned under `docs/releases/` for v0.2.3 and v0.2.4.

### 🛠️ Carried over from v0.2.3

- One shared domain, node selected by `?user=` (no per-device subdomains or SANs).
- A unique `Mcp-Session-Id` per session.
- `/sse` and `/mcp` answer in the POST body only — the fix that made Gemini Spark work.
- `GET /mcp` carries JSON-RPC frames only.
- A non-zero exit code is a command result, not an unreachable node.
- Gateway operations: `deploy_gateway.sh`, `ops/nginx/`, `GEMINI_APP_INSTRUCTIONS.md`.

### 📦 Package

`gemini-computer-use@0.2.4` — 20 files, no build artifacts, no credentials.
